# UI/UX Design Direction

## 1. Design Theme
Use a clean, modern blue-and-white design suitable for a college project.

## 2. Color Palette
- Navy Blue: RGB(20, 55, 100)
- Primary Blue: RGB(40, 110, 190)
- Light Background: RGB(242, 247, 252)
- White: RGB(255, 255, 255)
- Success: Green
- Cancellation/Error: Red

## 3. Typography
- Font: Segoe UI
- Main title: Bold, 23 pt
- Section headings: Bold, 18 pt
- Table text: 12–14 pt

## 4. Dashboard Layout
- Header: Railway Reservation System title.
- Main section: Available Trains.
- Center: Train details table.
- Action buttons:
  - Refresh Trains
  - Book Ticket
  - My Tickets
  - Cancel Ticket

## 5. Train Table
Display:
- Train ID
- Train Number
- Train Name
- Source Station
- Destination Station
- Departure Time
- Arrival Time
- Available Seats
- Fare

## 6. User Experience
- Keep buttons easy to understand.
- Show clear success and error messages.
- Ask for confirmation before cancelling a ticket.
- Display the PNR clearly after successful booking.
- Refresh train information after booking or cancellation.
- Keep the dashboard simple and easy to navigate.

## 7. Navigation
Open the dashboard directly when the application starts. Do not add a login page.

## 8. Responsiveness
Use suitable layouts, spacing, and scrollable tables so the interface remains usable when the window is resized.
